# NordFlow Tasks

Адаптивный внутренний трекер проектов и задач компании NordFlow (MVP).

## Запуск

Приложение не требует сборки и установки зависимостей. Откройте `index.html` в современном браузере (Chrome, Edge, Firefox, Safari) двойным щелчком.

При желании можно запустить локальный сервер:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Что реализовано

- Авторизация (вход/выход, показ пароля, сообщения об ошибках, сохранение сессии после обновления страницы).
- Три роли: администратор, руководитель проекта, сотрудник — с разными правами.
- Разделы: «Главная», «Мои задачи», «Проекты», «Команда», «Уведомления», «Настройки профиля», «Пользователи» (администратор).
- Главная: метрики, ближайшие дедлайны, последние обновления, мои проекты, сводка по команде для руководителя.
- Мои задачи: поиск, фильтры (статус, проект, приоритет, срок, просроченные), режимы «Список» и «Доска».
- Проекты: карточки с прогрессом, создание/редактирование, страница проекта с вкладками «Доска», «Список задач», «Участники», «Информация».
- Kanban-доска с 5 колонками и перетаскиванием карточек (на смартфоне — горизонтальная прокрутка и переключатель колонок).
- Задачи: создание, редактирование, комментарии (редактирование/удаление своих, удаление любых — администратор), история изменений, вложения (ссылки и файлы), теги.
- Уведомления внутри приложения: назначение, изменение срока/статуса, комментарии, приближающийся и просроченный дедлайн.
- Команда: загрузка сотрудников, активные и просроченные задачи.
- Профиль: личные данные, фотография, смена пароля, светлая/тёмная тема.
- Глобальный поиск по проектам, задачам и сотрудникам с группировкой результатов.
- Адаптивная вёрстка: боковое меню на компьютере, гамбургер и карточки на смартфоне.
- Демо-данные: 8 пользователей, 3 проекта, 31 задача, комментарии и история изменений.

## Деплой на Railway

Подробная пошаговая инструкция — в [DEPLOY.md](DEPLOY.md). Кратко: в проекте есть `package.json` и `server.js` (статический сервер без зависимостей, слушает `$PORT`), поэтому Railway поднимает приложение командой `npm start`. Можно задеплоить через GitHub (New Project → Deploy from GitHub repo → Generate Domain) либо локально: `railway login`, `railway init`, `railway up`, `railway domain`.

## Данные

Все изменения сохраняются в `localStorage` браузера (`nordflow_tasks_state_v2`), поэтому данные не исчезают после обновления страницы. Ключ версионирован: при обновлении версии приложения данные автоматически возвращаются к исходному демо-набору.

Чтобы вернуть исходные демонстрационные данные, выполните в консоли браузера:

```js
NF.resetData();
localStorage.removeItem('nordflow_tasks_session_v1');
location.reload();
```
